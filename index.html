Personal backup utility

vps-backup

Encrypted server backups stored in the owner's Google Drive.

This private-use desktop OAuth client connects rclone to Google Drive. Restic encrypts backup data before rclone uploads it. Healthchecks.io monitors job completion and sends email alerts.

Limited Google Drive access

The application requests only the drive.file scope. It can create and manage the specific files and folders it creates or that the owner explicitly makes available to it.

This utility is operated by the owner of the vaseo1 GitHub account for personal use. It does not offer public registration or a hosted backup service.
