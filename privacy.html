Privacy policy

Effective October 23, 2026.

Purpose and Google data access

vps-backup is a personal utility operated by the owner of the vaseo1 GitHub account to store encrypted server backups in that owner's Google Drive. It uses the Google Drive API with the drive.file scope to create, list, read, update and remove backup files and folders available to this application. It does not request access to Gmail, contacts, calendars, or the contents of unrelated Drive files.

Use, storage and sharing

Restic encrypts backup contents before rclone sends them to Google Drive over HTTPS. OAuth credentials are kept in access-restricted files on the owner's machines. The restic repository password is stored separately from the encrypted backup data, including a copy in the owner's Mac Keychain. Healthchecks.io receives job status signals for email alerts; backup contents are not sent to it.

Google user data is used only to operate and restore the owner's backups. It is not sold, used for advertising, shared with unrelated parties, or used to train AI models. vps-backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and control

The owner controls backup retention and can remove backups from Google Drive, empty Drive trash, and revoke this application's access in Google Account settings. Revoking access prevents future authorized API operations but does not itself delete existing backup files. Locally retained credentials can be removed from the owner's machines. Restoring encrypted backups requires the repository password.

This website

This informational site runs on GitHub Pages. It has no application login, analytics scripts, tracking cookies, credential forms, or access to backups. GitHub may process request information according to its own privacy statement.

Contact

Contact the operator through the project's GitHub issues. Do not post credentials, backup contents or other private information.
